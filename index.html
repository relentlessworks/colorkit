colorkit

Agentic-first color manipulation service. Convert, mix, analyze, and generate color palettes. Plain text API, agent-driven, single Go binary.

Endpoints

GET /convert — Convert hex/RGB/HSL

GET /mix — Mix two colors

GET /lighten — Lighten color

GET /darken — Darken color

GET /saturate — Increase saturation

GET /desaturate — Decrease saturation

GET /grayscale — Convert to grayscale

GET /invert — Invert color

GET /rotate — Rotate hue

GET /complement — Complementary color

GET /analogous — Analogous colors

GET /triadic — Triadic colors

GET /tetradic — Tetradic colors

GET /contrast — WCAG contrast ratio

GET /suggested-text — Best text color

GET /gradient — Color gradient

GET /shades — Darker shades

GET /tints — Lighter tints

Quick Start

# Convert a color
curl "http://localhost:7100/convert?color=#ff0000"
# hex=#ff0000 rgb=255,0,0 hsl=0,100,50

# Mix two colors
curl "http://localhost:7100/mix?c1=#ff0000&c2=#0000ff&ratio=0.5"

# Check contrast
curl "http://localhost:7100/contrast?c1=#000000&c2=#ffffff"
# ratio=21.00 wcag_aa=pass wcag_aaa=pass

# Generate a gradient
curl "http://localhost:7100/gradient?c1=#ff0000&c2=#0000ff&steps=5"

Principles

Plain text by default JSON on demand Instructive errors Self-documenting MCP connector Single Go binary Zero config No database
